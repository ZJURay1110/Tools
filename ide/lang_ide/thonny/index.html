    Thonny¶

    面向 Python 纯新手设计的 IDE，变量可视化与步进调试是其独特的教学利器

    前言¶

    学习编程最大的障碍不是"写什么代码"，而是"代码运行时到底发生了什么"。传统的 IDE 隐藏了执行细节，初学者面对什么也不显示的代码和执行到一半崩掉的控制台，无法建立对程序模型的基本认知。

    Thonny 是芬兰赫尔辛基大学开发的 Python IDE，专门针对这一问题设计。它在编辑器旁边添加了一个变量面板，实时显示所有变量的值和类型；步进 F6 时，变量面板同步更新，让初学者的脑海中形成"代码在内存中逐行改变数据"的心智模型。

    本机版本： 4.1.6
    平台： Windows / macOS / Linux
    许可证： MIT（免费开源）

    1 概述¶

    1.1 目标用户¶

    Thonny 的设计目标非常明确且狭窄：刚接触编程的大学一年级学生。它最适用的三个场景：

    • 大学 CS101 课程的教学环境
    • 高中信息技术课的编程模块
    • 零基础自学 Python 的前 4 周

    一旦学习者掌握了变量、条件、循环、函数的基本概念，Thonny 的功能边界就会很快触及。此时换到 VS Code 或 PyCharm 是合适的。但它在"学编程的起步阶段"做的大多数其他 IDE 要好。

    1.2 设计哲学¶

    • 零配置：安装后直接打开，不需要配置 Python 解释器、安装 pylint 或设置任何东西
    • 隐藏复杂性：默认隐藏文件管理器、命令行、Git 集成等功能
    • 逐步暴露：当用户需要更多功能时，视图 → 文件、视图 → Shell 等逐步解锁

    2 核心功能¶

    2.1 变量浏览器¶

    Thonny 最核心的功能。在 Thonny 中运行代码，编辑器右侧的面板显示当前作用域内所有变量的名称、类型和值：

    # 在 Thonny 中运行这段代码并单步执行（F6）
x = 42
y = [1, 2, 3]
name = "Alice"

# 变量面板会实时显示：
# x: int  → 42
# y: list → [1, 2, 3]
# name: str → 'Alice'

    当循环变量变化时，面板中的值会闪烁变化，建立"变量是内存中一个有名字的盒子"这一心智模型。

    2.2 步进调试¶

    Thonny 的调试与变量面板高度集成：每按一次 F6（Step Over），面板中的变量值同步更新。有些 Thonny 版本还在栈帧区域显示每个变量在内存中的地址。

    2.3 表达式树可视化¶

    在调试模式中选中一个表达式（如 (x + y) * z），Thonny 在旁边显示这颗表达式的语法树逐层计算结果。这帮助初学者理解运算符优先级和函数调用嵌套。

    2.4 简单包管理器¶

    Tools → Manage packages 提供一个最小化的包管理器图形界面，用于安装 pip 包。它不会报出复杂的 pip 版本兼容性错误，如果安装失败它会显示人类可读的提示。

    3 安装与配置¶

    3.1 系统需求¶

    • 操作系统：Windows 7+ / macOS 10.13+ / Linux（主流的发行版）
    • Python：不需要预先安装。Thonny 自带一个完整的 Python 3.10（包括 pip）
    • 磁盘：安装后约 200 MB

    3.2 安装¶

    1. 访问 https://thonny.org

    2. 根据操作系统下载：

    3. Windows：直接下载 .exe 运行

    4. macOS：下载 .dmg 文件点击安装

    5. Linux：使用包管理器（sudo apt install thonny）或 Flatpak

    6. 安装完成即可打开使用

    7. 首次打开时，选择语言（简体中文）和初始设置

    3.3 使用建议¶

    • 初学阶段建议关闭"文件管理器"视图（View → 取消勾选 File ），减少视觉干扰
    • 在教学完循环和列表后，可以考虑开启 Shell（View → Shell），让学生开始接触命令行交互
    • 在讲解函数作用域时，可以引导学生观察变量面板在进入函数前后局部变量和全局变量的变化

    4 常用操作¶

    操作 快捷键
    运行当前程序 F5
    步进（Step Over） F6
    步进进入函数 F7
    跳出函数 F8
    设置/清除断点 点击行号左侧
    运行到光标 右键 → 执行到光标处
    注释/取消注释 Ctrl+3 / Ctrl+4
    代码补全提示 Ctrl+Space

    6 注意事项¶

    何时脱离 Thonny

    当学习者开始问以下问题时，就是切换到 VS Code 或者 PyCharm 的信号： - "怎么在同一个文件中写多个函数然后从不同入口调用？" - "Thonny 怎么调大字体？" - "怎么在多个文件中组织代码模块？"

    Thonny 与系统 Python 包隔离

    Thonny 自带一个隔离的 Python 解释器，在 Thonny 中用 pip 安装的包不会影响系统 Python，反过来也一样。如果需要在 Thonny 中使用已安装的第三方包（如 numpy、pandas），需要单独在 Thonny 的包管理器中安装。
