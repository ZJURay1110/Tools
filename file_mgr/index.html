    文件管理¶

    1 分类简介¶

    软件工程的日常中，大量时间花在"找文件"和"整理文件"上。文件管理工具的目标是将这些操作从分钟级压缩到秒级，从手动变成自动。

    根据场景快速选择： - 全盘秒搜文件 → Everything - 替代资源管理器 → Total Commander 或 One Commander - 磁盘空间去哪儿了 → SpaceSniffer 或 WizTree - 压缩打包 → 7-Zip 或 WinRAR - 自动增量备份 → FreeFileSync - 清理重复文件 → dupeGuru

    2 为什么需要这些工具¶

    场景 痛点 解决工具
    找文件 系统搜索速度慢、不支持高级过滤 文件搜索增强工具毫秒级定位
    磁盘空间告急 不知道哪些文件夹占最大空间 磁盘分析工具可视化空间分布
    打包分发 内置 zip 压缩率低、不支持 rar 压缩解压工具多格式 + 高压缩率
    备份数据 手动复制容易漏文件、覆盖失误 同步备份工具增量 + 双向同步
    磁盘接近满 重复文件浪费大量空间难以手工清理 重复文件清理工具扫描内容指纹

    3 子分类速览¶

    3.1 资源管理器增强¶

    替代或增强系统自带的文件资源管理器，显著提升文件操作效率。

    工具 一句话
    Everything NTFS 磁盘毫秒级文件名搜索，开发必备
    Total Commander 双面板文件管理的经典，强在批量操作和快捷键
    One Commander 现代 UI 的双面板管理器，分栏 + 预览
    Directory Opus Windows 上最强资源管理器替代，几乎没有做不到的

    进入资源管理器增强分类

    3.2 磁盘空间分析¶

    可视化展示磁盘空间被哪些文件夹/文件占用，一秒定位大文件。

    工具 一句话
    SpaceSniffer 区块地图可视化，直观到大文件层次
    WinDirStat 经典树状图 + 网格块图，最适合报告截图
    TreeSize 按文件夹树排序显示占用，支持导出报告
    WizTree 速度最快的磁盘分析，秒扫数百 GB

    进入磁盘空间分析分类

    3.3 压缩解压¶

    支持多格式的压缩与解压工具，覆盖日常打包和镜像分发场景。

    工具 一句话
    7-Zip 开源免费、压缩率之王、支持几乎所有格式
    WinRAR RAR 格式的发明者，生态最广的压缩工具
    PeaZip 开源、支持加密和分卷的自定义方案

    进入压缩解压分类

    3.4 同步备份¶

    自动比对本机与目标目录的文件差异，增量同步而非全量复制。

    工具 一句话
    FreeFileSync 最流行的开源文件同步工具，界面直观
    GoodSync 双端同步 + 版本历史，支持多种存储后端

    进入同步备份分类

    3.5 重复文件清理¶

    扫描磁盘中内容完全重复的文件，一键清理释放空间。

    工具 一句话
    dupeGuru 按文件名/大小/内容模糊匹配，最主流的去重工具
    Czkawka 更快、跨平台、去重功能更强大的 Rust 实现

    进入重复文件清理分类
