# editor — 通用编辑器

## 定位

收录不绑定特定编程语言的通用编辑工具，分为照片图像与文本两大分支。

## 子分类目录结构

```
editor/
├── photo/                    # 照片图像
│   ├── img_view/             #   图片查看器
│   │   ├── honeyview.md
│   │   ├── irfanview.md
│   │   └── faststone_image_viewer.md
│   ├── img_edit/             #   图像编辑
│   │   ├── gimp.md
│   │   ├── paint_net.md
│   │   ├── affinity_photo.md
│   │   └── inkscape.md
│   ├── screen_cap/           #   截图工具
│   │   ├── snipaste.md
│   │   ├── sharex.md
│   │   └── flameshot.md
│   └── screen_rec/           #   屏幕录制
│       ├── obs_studio.md
│       └── bandicam.md
└── text/                     # 文本
    ├── txt_edit/             #   纯文本编辑器
    │   ├── notepad_plus_plus.md
    │   ├── sublime_text.md
    │   ├── vim.md
    │   └── emacs.md
    ├── md_note/              #   Markdown 与笔记
    │   ├── typora.md
    │   ├── obsidian.md
    │   ├── marktext.md
    │   └── notion.md
    └── office/               #   办公套件
        ├── libreoffice.md
        └── onlyoffice.md
```

## 编写要点

- 照片编辑器需标注图层/批量处理/RAW 支持
- 截图工具侧重标注功能、滚动截屏、贴图能力
- 文本编辑器对比启动速度、大文件处理、插件生态
