# 通用编辑器

---

## 1 分类简介

代码之外，开发者的工作流还涉及大量非代码内容：设计图、截图、文档、笔记和办公文件。通用编辑器覆盖了从看图修图到笔记办公的全场景。

!!! tip ""
    根据场景快速选择：
    - 快速看图 → [Honeyview](photo/img_view/honeyview.md) 或 [IrfanView](photo/img_view/irfanview.md)
    - 修图 / 做海报 → [GIMP](photo/img_edit/gimp.md) 或 [Paint.NET](photo/img_edit/paint_net.md)
    - 截图标注 → [Snipaste](photo/screen_cap/snipaste.md) 固定贴图天花板
    - 录屏 / 直播 → [OBS Studio](photo/screen_rec/obs_studio.md)
    - 轻量文本编辑器 → [Notepad++](text/txt_edit/notepad_plus_plus.md) 或 [Sublime Text](text/txt_edit/sublime_text.md)
    - Markdown 笔记 → [Typora](text/md_note/typora.md) 或 [Obsidian](text/md_note/obsidian.md)
    - 办公文档 → [LibreOffice](text/office/libreoffice.md)

---

## 2 为什么需要这些工具

| 场景 | 痛点 | 解决工具 |
|------|------|---------|
| 看设计图 / 照片 | 系统图片浏览器功能太少不能批量 | 图片查看器快速浏览 + 批量处理 |
| 技术文档配图 | 需要截图标注、箭头、马赛克 | 截图工具贴图 + 标注一条龙 |
| 修图、做图标 | 打开 PS 太重太慢 | 轻量图像编辑快速处理 |
| 制作教学视频 | 没有简单好用的录屏工具 | 屏幕录制工具 OBS / Bandicam |
| 编辑代码 / 配置文件 | 系统记事本功能太弱 | 文本编辑器语法高亮 + 宏支持 |
| 写技术文档 | Word 太重、不适合 Markdown | Markdown 笔记预览即所得 |
| 打开用户提供的 Word/Excel | 没有 Office 授权 | 免费办公套件兼容格式 |

## 3 子分类速览

### 3.1 图片查看器

快速浏览图片，支持批量管理和简单编辑。

| 工具 | 一句话 |
|------|--------|
| Honeyview | 启动最快的看图软件之一，支持 PSD / RAW |
| IrfanView | 老牌 Windows 看图软件，批量转换功能强 |
| FastStone Image Viewer | 看图 + 批量改名 + 格式转换一体 |

> [进入图片查看器分类](photo/img_view/index.md)

### 3.2 图像编辑

从简单裁剪到专业调色，覆盖日常和进阶需求。

| 工具 | 一句话 |
|------|--------|
| GIMP | 开源 Photoshop 替代，生态完整 |
| Paint.NET | 轻量级图像编辑，学习成本最低的入门方案 |
| Affinity Photo | 专业商业修图软件，买断制无订阅 |
| Inkscape | 开源矢量绘图工具，类似 Adobe Illustrator |

> [进入图像编辑分类](photo/img_edit/index.md)

### 3.3 截图工具

截图 + 标注 + 贴图，技术文档和 Bug 报告的标配生产力工具。

| 工具 | 一句话 |
|------|--------|
| Snipaste | 截图固定贴图，看代码对照的终极方案 |
| ShareX | 开源截图 + 录屏 + OCR + 上传全功能 |
| Flameshot | Linux 上最好用的截图标注工具 |

> [进入截图工具分类](photo/screen_cap/index.md)

### 3.4 屏幕录制

桌面录屏、直播推流、视频剪辑。

| 工具 | 一句话 |
|------|--------|
| OBS Studio | 开源直播/录屏标准，功能最强扩展最多 |
| Bandicam | Windows 录屏老牌付费软件，压缩率出色 |

> [进入屏幕录制分类](photo/screen_rec/index.md)

### 3.5 文本编辑器

不绑定 IDE 的独立文本编辑工具，适合快速编辑代码和文本文件。

| 工具 | 一句话 |
|------|--------|
| Notepad++ | Windows 老牌轻量文本编辑器，插件丰富 |
| Sublime Text | 极致启动速度和流畅编辑体验 |
| Vim | 类 Unix 系统的终端编辑器，快捷键体系强大 |
| Emacs | 可编程编辑器，本质是一个 Lisp 运行时 |

> [进入文本编辑器分类](text/txt_edit/index.md)

### 3.6 Markdown 笔记

面向技术写作的 Markdown 编辑器，替代 Word 做文档。

| 工具 | 一句话 |
|------|--------|
| Typora | 所见即所得 Markdown 编辑器，流畅到极致 |
| Obsidian | 本地 Markdown 笔记 + 双向链接知识图谱 |
| MarkText | 开源的 Typora 替代品 |
| Notion | 云端笔记 + 数据库 + 项目管理一体 |

> [进入 Markdown 笔记分类](text/md_note/index.md)

### 3.7 办公套件

兼容 Microsoft Office 格式的免费办公软件。

| 工具 | 一句话 |
|------|--------|
| LibreOffice | 开源办公套件，文档兼容性最好的免费方案 |
| OnlyOffice | 与 Office 365 在线协作兼容的桌面套件 |

> [进入办公套件分类](text/office/index.md)
