# ide — 代码编写

## 定位

收录代码编辑与项目开发所使用的集成开发环境（IDE），按通用型与语言专用型分类。

## 子分类目录结构

```
ide/
├── gen_ide/                  # 通用 IDE
│   ├── visual_studio_code.md
│   ├── visual_studio.md
│   ├── eclipse.md
│   ├── code_blocks.md
│   └── cursor.md
├── manage/                  # 环境配置
│   ├── nodejs.md
│   ├── vs_installer.md
│   ├── jetbrains_toolbox.md
│   └── anaconda.md
└── lang_ide/                 # 单语言专用 IDE
    ├── pycharm.md
    ├── clion.md
    ├── matlab.md
    ├── dev_cpp.md
    ├── thonny.md
    └── arduino_ide.md

```

## 编写要点

- 每个 IDE 页需说明支持的语言、平台、是否免费
- 侧重安装配置与常用插件/扩展推荐
- 通用 IDE 强调多语言支持对比；专用 IDE 强调语言特化功能
