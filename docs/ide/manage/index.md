# IDE 环境配置
*开发者机器上编程环境的配置、安装器与运行时管理工具*


---

## 前言

环境配置是开发工作的起点。一个整洁、可控的编程环境可以减少大量"在我电脑上可以跑"的沟通成本和"编译器找不到"的调试时间。本目录收录的并非 IDE 本身，而是与 IDE 配合使用的前置安装器和运行时工具，它们在大型项目初期决定整个团队的协作基础和长期维护成本。

!!!

## 1 本类目收录工具

| 工具名称 | 一句话描述 | 平台 | 许可证 |
|---------|-----------|------|--------|
| [Node.js](nodejs.md) | JavaScript/TypeScript 运行时，前端生态的核心依赖 | Windows / macOS / Linux | MIT（免费） |
| [Visual Studio Installer](vs_installer.md) | Visual Studio 的模块化安装器，工作负载和组件管理 | Windows | 免费 |
| [JetBrains Toolbox](jetbrains_toolbox.md) | JetBrains 全家桶管理入口，安装/更新/授权/启动 | Windows / macOS / Linux | Toolbox 免费 |
| [Anaconda](anaconda.md) | Python 数据科学环境管理器，包与虚拟环境的管理员 | Windows / macOS / Linux | 免费开源 |

## 2 各工具适用场景

| 场景 | 推荐 |
|------|------|
| Web 前端 / SSR 开发 | Node.js（必装） |
| 需要多个 C#/C++ 项目版本 | Visual Studio Installer |
| 使用多种 JetBrains IDE | JetBrains Toolbox |
| Python 数据科学 / 多 Python 版本 | Anaconda |
