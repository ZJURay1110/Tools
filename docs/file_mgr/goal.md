# file_mgr — 文件管理

## 定位

收录本地文件系统管理工具，包括文件搜索与浏览增强、磁盘空间分析、压缩解压、同步备份、重复文件清理。

## 子分类目录结构

```
file_mgr/
├── explorer/                 # 文件资源管理器增强
│   ├── everything.md
│   ├── total_commander.md
│   ├── one_commander.md
│   └── directory_opus.md
├── disk_scan/                # 磁盘空间分析
│   ├── spacesniffer.md
│   ├── windirstat.md
│   ├── treesize.md
│   └── wiztree.md
├── compress/                 # 压缩解压
│   ├── 7zip.md
│   ├── winrar.md
│   └── peazip.md
├── sync/                     # 同步备份
│   ├── freefilesync.md
│   └── goodsync.md
└── dedup/                    # 重复文件清理
    ├── dupeguru.md
    └── czkawka.md
```

## 编写要点

- 标注操作系统支持
- 压缩工具需列出支持的格式及压缩率对比
- 文件搜索工具重点关注索引速度与高级过滤语法
