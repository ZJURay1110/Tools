# dev_utils — 开发辅助工具

## 定位

收录不直接参与代码编写但对开发流程关键的辅助工具，包括版本控制、终端模拟器、差异对比合并、虚拟机与容器环境、系统监控。

## 子分类目录结构

```
dev_utils/
├── vcs/                      # 版本控制
│   ├── git.md
│   ├── github_desktop.md
│   ├── sourcetree.md
│   └── lazygit.md
├── terminal/                 # 终端模拟器
│   ├── windows_terminal.md
│   ├── cmder.md
│   ├── warp.md
│   └── tabby.md
├── diff/                     # 差异对比与合并
│   ├── beyond_compare.md
│   ├── meld.md
│   └── winmerge.md
├── vm/                       # 虚拟机与环境
│   ├── vmware_workstation.md
│   ├── virtualbox.md
│   └── wsl.md
├── sys_mon/                  # 系统监控
│   ├── process_explorer.md
│   ├── hwinfo.md
│   └── cpu_z.md
└── doc/                      # 文档生成
    ├── doxygen.md
    └── sphinx.md
```

## 编写要点

- Git 工具区分命令行与 GUI，说明分支可视化能力
- 终端模拟器比较 GPU 加速、分屏、主题定制
- Diff 工具说明三方合并、目录对比、二进制文件处理
