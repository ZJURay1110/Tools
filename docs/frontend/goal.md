# frontend — 前端开发

## 定位

收录 Web 前端开发链工具，涵盖浏览器开发者工具、包管理器、构建工具、UI 框架与组件库、代码检查与格式化。

## 子分类目录结构

```
frontend/
├── browser_dt/               # 浏览器开发者工具
│   ├── chrome_devtools.md
│   └── firefox_devtools.md
├── pkg_mgr/                  # 包管理器
│   ├── npm.md
│   ├── yarn.md
│   └── pnpm.md
├── build/                    # 构建工具
│   ├── vite.md
│   ├── webpack.md
│   ├── esbuild.md
│   └── rollup.md
├── framework/                # 前端框架
│   ├── react.md
│   ├── vue.md
│   ├── angular.md
│   └── svelte.md
├── ui_lib/                   # UI 组件库
│   ├── tailwind_css.md
│   ├── bootstrap.md
│   ├── element_plus.md
│   └── ant_design.md
└── lint/                     # 代码检查与格式化
    ├── eslint.md
    └── prettier.md
```

## 编写要点

- 包管理器侧重安装速度、monorepo 支持、lockfile 机制对比
- 构建工具说明开发/生产模式差异与 HMR 支持
- 框架与 UI 库关注生态规模、学习曲线、适用项目类型
