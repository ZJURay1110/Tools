# gis — GIS 开发

## 定位

收录地理信息系统相关开发工具，覆盖桌面 GIS、服务端 GIS、空间数据库、Web GIS 前端框架、空间数据处理与遥感。

## 子分类目录结构

```
gis/
├── desktop/                  # 桌面 GIS
│   ├── arcgis_pro.md
│   ├── qgis.md
│   └── arcgis_desktop.md
├── server/                   # 服务端 GIS
│   ├── geoserver.md
│   ├── arcgis_server.md
│   └── arcgis_enterprise.md
├── spatial_db/               # 空间数据库
│   ├── postgis.md
│   ├── spatialite.md
│   └── oracle_spatial.md
├── webgis/                   # Web GIS 前端框架
│   ├── leaflet.md
│   ├── openlayers.md
│   ├── mapbox_gl_js.md
│   ├── cesium.md
│   └── deck_gl.md
├── spatial_tool/             # 空间数据处理工具
│   ├── gdal.md
│   ├── ogr2ogr.md
│   ├── geopandas.md
│   └── fiona.md
└── rs/                       # 遥感
    ├── envi.md
    ├── erdas_imagine.md
    ├── google_earth_engine.md
    └── snap.md
```

## 编写要点

- 桌面 GIS 对比分析/可视化/编辑/制图能力差异
- 服务端 GIS 关注 OGC 标准支持（WMS/WFS/WCS/WPS）
- Web GIS 框架说明 2D/3D 能力、矢量切片、底图源支持
